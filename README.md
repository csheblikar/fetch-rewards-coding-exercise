# fetch-rewards-coding-exercise

## ✨ Features

-  Fetches and parses remote JSON data using **Retrofit**
- Displays items in grouped sections using **Jetpack Compose**
- Collapsible (accordion-style) UI to expand only one group at a time
- Clean and responsive UI using **Material 3**
- Filters invalid entries before rendering

---

## 🛠️ Tech Stack

- **Kotlin**
- **Jetpack Compose**
- **Retrofit2 + Gson**
- **Material 3**
- **MVVM architecture**
